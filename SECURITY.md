# Security policy

`holochain-cose` is pre-release. No version is supported for production use, and no release
has been made.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **"Report a
vulnerability"** button (Security tab → Advisories) on this repository. Don't open a public
issue for a security problem.

Include the affected commit, a description, and a reproducer if you have one. Reports are
acknowledged on a best-effort basis while the project is pre-release.

## Scope notes

Until the relevant independent security reviews have been completed and recorded, nothing in
this repository should be relied on for cryptographic assurance. A valid signature is not
evidence of trusted authorisation, verified document content, workflow finality, trusted
signing time or human consent. The project treats each of these as a separate claim.
